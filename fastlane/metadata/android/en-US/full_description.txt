One More Step is a minimalist, battery-efficient step-tracking application built with modern Android standards.

The app is optimized for OLED screens, using a "True Black" theme (#000000) to draw zero power on black pixels. It leverages hardware-level sensors (Sensor.TYPE_STEP_COUNTER and Sensor.TYPE_STEP_DETECTOR) with batching to minimize CPU wake-ups, drastically reducing battery drain.

Features:
- True Black Dark Mode: Optimized for OLED pixels.
- Hardware-Level Tracking: Reliable and efficient step counting.
- Pause/Resume: Full control over your tracking sessions.
- Dynamic Goals: Set custom daily targets.
- Session History: Automatically saves your walks to a local Room database.
- Monochrome Branding: High-contrast, sleek aesthetic.

Built with Jetpack Compose, Room Database, and Android Foreground Services. Vibecoded by Gemini.
